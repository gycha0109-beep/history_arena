# Legendary Battle (레전더리 배틀)

> **프로젝트 공식 기준 문서 — 2026-11-12 / 기획·기술 스택 확정, 구현 착수 전**

## 1. 프로젝트 목적

서로 다른 시대의 전설적인 인물들이 각자의 전투 특성을 살려 **AI 자율 대전**을 벌이는 격투 시뮬레이터를 만들고, 그 경기에서 **고품질 세로형 숏폼 영상(릴스·쇼츠·틱톡)**을 지속적으로 제작한다.

- **최종 제품:** 게임 판매가 아닌 가상 대전 영상 콘텐츠 생산 시스템
- **초기 대전:** 미야모토 무사시 vs 이소룡
- **초기 목표:** 두 캐릭터의 완성도 높은 대전 1개
- **그래픽 방향:** 고품질 반실사, 2D 격투게임처럼 보이는 **3D 기반 2.5D**
- **영상:** 세로 9:16, 30~60초, 1080×1920·60fps 출력 목표
- **개발 환경:** Windows PC, **GTX 1070**을 기준으로 성능·제작 비용 고려

## 2. 확정 기술 스택

| 영역 | 확정 기술 | 용도 |
|---|---|---|
| 게임 엔진 | **Godot 4.x** | 전투 시뮬레이션, 판정, AI, 카메라, 렌더링 |
| 게임 개발 언어 | **GDScript** | 전투·캐릭터·AI·경기 관리 |
| 캐릭터/애니메이션 제작 | **Blender** | 3D 모델·리깅·모션 수정·무기 결합 |
| 기본 모션 확보 | **Adobe Mixamo** | 사용 가능한 기본 모션 재활용 |
| 캐릭터 렌더링 | **실시간 3D 기반 2.5D** | 2D 대전 구도로 3D 캐릭터 표시 |
| 전투 AI | **규칙 기반 + 유틸리티 AI** | 자율 행동 선택, 상황 판단 |
| 경기 기록 | **JSON 기반** | 경기 결과·행동 기록·재생용 데이터 |
| 영상 출력 | **Godot Movie Maker + FFmpeg** | 프레임/영상 출력 및 인코딩 |
| 제작 자동화 | **Python** | 경기 실행·선택·영상 처리 자동화 |
| 버전 관리 | **Git + Git LFS** | 소스 코드와 대용량 에셋 관리 |
| 개발 도구 | **VS Code** | 코드 작성·관리 |

**기술 선정은 고정한다.** 개별 도구의 정확한 버전은 최초 개발 환경 구성 시 호환성을 확인하여 잠그며, 이후에는 검증된 기술적 장애가 있을 때만 변경한다.

### 기본 제작 파이프라인

1. 캐릭터용 3D 모델 확보·제작
2. Blender에서 리깅·무기 연결 및 모션 수정
3. Mixamo 등에서 확보한 사용 가능한 모션 재활용
4. Godot에서 2.5D 전투 화면과 캐릭터 상태·충돌 판정 구성
5. AI 자율 대전 실행, 결과와 재생에 필요한 데이터 기록
6. 선택한 경기 재생, 시네마틱 카메라·이펙트 적용
7. Movie Maker 및 FFmpeg로 세로형 영상 출력

## 4. 구현 원칙

- **전투 판정과 화면 연출을 분리**한다. 카메라·이펙트가 승패에 영향을 주지 않는다.
- 캐릭터의 위치, 무기 연결, 공격 판정, 피격 판정, 애니메이션 상태를 명확히 구분한다.
- **검 길이 변화, 무기 늘어짐, 발 미끄러짐, 신체 비율 왜곡**을 허용 가능한 최종 품질로 취급하지 않는다.
- AI는 실제로 공격·방어·회피·이동을 판단한다. 결과를 미리 정한 영상을 '시뮬레이션'으로 소개하지 않는다.
- 동일한 경기를 재생할 수 있도록 난수 시드만이 아니라 입력·이벤트·엔진 버전 등 필요한 기록 범위를 설계한다.
- GTX 1070 환경에서 **실시간 시뮬레이션과 고품질 최종 영상 출력은 분리**한다.
- 캐릭터·모션·기술 데이터를 재사용 가능한 구조로 만들어 새 캐릭터 추가 비용을 줄인다.
- 2D 스프라이트 시트와 생성형 영상의 프레임 추출은 **기본 제작 파이프라인에서 제외**한다. Google Flow 등은 참고·보조용으로만 활용한다.
- 사용한 모델·모션·음원·에셋과 실존 인물의 상업적 이용 권리를 공개 전에 확인한다.

## 5. 첫 번째 개발 목표

**첫 검증: Godot에서 무사시와 이소룡이 자연스럽게 움직이는 5초 전투 장면.**

예시: 대치 → 접근 → 무사시 검격 → 이소룡 피격 또는 회피 → 자세 회복.

이 5초 장면은 **그래픽·애니메이션 품질 검증용 고정 시퀀스**다. AI 자율 대전 완성과 혼동하지 않는다.

### 통과 기준

- 무사시의 검 길이·손 연결 위치·신체 비율이 동작 내내 일관적이다.
- 이동·검격·피격 애니메이션이 부자연스러운 늘어짐이나 발 미끄러짐 없이 재생된다.
- Godot 엔진에서 실제로 장면이 재생된다.
- 영상 파일을 출력하고 결과물을 검토할 수 있다.
- 캐릭터나 모션을 추가할 때 기존 구조를 재사용할 수 있다.
