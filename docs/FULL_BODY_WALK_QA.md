# 2026-11-13 — 5초 전신 보행 재검증

## 판정

기존 5초 군인 모델은 **시각 품질 불합격**입니다. 왼발 걸림과 상체/팔의 무작위처럼 보이는 움직임을 해결하지 못했습니다. 특히 골반·다리만 있는 모션캡처(8개 채널)에 주기가 다른 상체 동작을 합성한 시도와 임의 발목 회전은 **제작 파이프라인에서 폐기**했습니다.

새 검증에서는 **하나의 전신 보행 애니메이션**을 사용했습니다. 이는 기존 군인 모델을 고친 것이 아니라 보행 제작 방식의 정당성을 검증하기 위해 **CC0 임시 인체 모델을 교체한 것**입니다.

## 실제 제작·검증 결과

- 모델·동작: KinemIQ free pack의 `KinemIQ_Mannequin.glb` 및 `Walk_forwards.glb`. 원본 Quaternius Universal Animation Library CC0.
- 원본 GLB 애니메이션: 전신 채널 **67개**. Godot에서 불필요한 정적 트랙을 최적화해 **56개 트랙**으로 읽음.
- 팔·어깨·척추·골반·다리는 **하나의 원본 동작**에 속합니다. 시점이 다른 상체 모션을 덧씌우지 않았습니다.
- 원본 골반 이동량 약 **1.356m / 1.3초**를 측정해 인체 위치 이동과 일치시켰습니다. 움직이는 발의 타이밍이나 관절 회전은 임의 수정하지 않았습니다.
- 실제 5초 이동: **5.215m**(초당 약 1.043m).
- 발을 딛는 구간 내 월드 좌표 수평 변화 최대: **0.039cm ≈ 0.39mm** (로컬 300프레임 검사).
- 양팔 프레임별 최대 회전: **2.64°** (로컬 300프레임 검사).
- 출력: **720×1280, 60fps, 300프레임, 5초 MP4**.
- Godot 4.7.2 stable / GTX 1060 3GB / FFmpeg를 실제 학원 PC에서 이용.
- 바닥 기준선과 카메라 추적 포함, HTML로 실패 영상과 수정 기준 영상을 동시에 보면서 프레임 이동 가능.

**주의:** 위 발 접지 오차는 발끝 근처의 **골격 관절 위치**를 측정한 값입니다. 실제 맨발 메시의 미세한 지면 교차를 완전히 검증한 수치는 아닙니다. 모션의 자연스러움은 영상으로 직접 확인해야 합니다.

## 아직 완료되지 않은 작업

1. 실제 무사시 캐릭터 모델에 전신 보행을 리타기팅한 뒤 똑같이 발/상체를 다시 검사할 것.
2. 검객의 전투 보행은 일반 보행과 달라 두 검을 쥔 손의 가드 자세를 갖춘 **별도 전신 모션**이 필요함. 어깨·팔꿈치·손목·손가락까지 정상 검술 그립을 확인해야 함.
3. 보행→정지→가드→검격→피격 반응을 5초 장면으로 시험.
4. 기존 군인 모델의 왼발 관통과 팔 튐을 수정했다고 오인하지 말 것. 그 실험은 **폐기**.

새 인체의 접지가 좋은 것은 유효한 기술 검증이지만 **사용자가 기대하는 최종 무사시 품질 통과를 의미하지 않습니다.**
