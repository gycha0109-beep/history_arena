## 다음 단계
1. H2.5 GLB는 참고용으로 보존. 기존 게임 모델을 자동 교체하지 않음.
2. H3.1 다운로드 가능성 및 합법적인 사용 권한을 확인한 뒤 실제 원본 확보 여부 결정.
3. 게임 캐릭터 제작은 고품질 모델을 확보한 뒤 얼굴·머리·의상 검수 → 무기 분리 → 최적화 → 리깅 순으로 진행.

이 보고서는 실제 Blender/GLB 분석 결과이며 원본보다 품질을 과장하지 않음.
