# 2026-11-12 보행 재보정: 왼발·상체

## 판정

새 5초 영상을 실제 Godot 4.7.2로 출력하고 프레임 비교를 했습니다.

- **왼발:** 뒤로 이동한 뒤 앞으로 발을 들어 올릴 때 발끝 관절이 지면 아래로 내려가던 구간을 확인했습니다. 원본 0.70초에서 발끝 관절 높이가 약 0.189m이었는데, 수정한 모션에서는 약 0.235m입니다. 약 **4.6cm 상승**.
- 바닥 높이도 첫 프레임 발목 높이에서 추정하는 대신 **한 보행 주기 양발 발끝의 높이 분포**로 보정했습니다. 최종 로컬 골격 검사에서 5초 동안 왼발의 전진 구간 최저 높이는 **지면 위 3.2cm**입니다.
- **상체:** 원래 `mocap_walk_F_1_1733` 클립은 골반과 다리 8개 항목만 움직였습니다. 별도로 존재하던 `walk`의 척추·어깨·양팔·손 애니메이션에서 13개의 회전 곡선을 가져와 보행 주기에 맞게 합성했습니다.
- 초기에 합성한 영상은 팔이 갑자기 들리는 문제가 있었으므로 **폐기**했습니다. 회전 범위를 제한하고 반복 구간을 부드럽게 연결해 재출력했습니다. 발 모션과 동기화된 작은 양팔 움직임도 완성된 애니메이션 데이터에 기록했습니다.
- 영상: **5초 · 60fps · 300프레임 · 720×1280**, 왼쪽 이전 후보, 오른쪽 새 수정본을 HTML로 나란히 비교할 수 있습니다.

## 확인할 로컬 파일

```text
D:\cha\History_arena\captures\walk\compare_reworked.html
D:\cha\History_arena\captures\walk\mocap_5s_compare.mp4
D:\cha\History_arena\captures\walk\mocap_5s_reworked.mp4
```

최신 수정본을 다시 생성:

```powershell
.\run-dev.cmd -Mode mocapfix
```

이 명령은 원본 라이선스 참조 GLB 검증 → 발/상체 애니메이션 합성 → 실제 모델 구조 검증 → 300프레임 녹화 → MP4 및 HTML 출력을 실행합니다. 제3자 모델·파생 GLB·영상은 로컬 `samples/external/`, `captures/`에만 두며 GitHub에 포함하지 않습니다.

## 기술적 변경

- `tools/author_mocap_composite.py`: 모션캡처의 골반/다리 키프레임과 다른 원본 동작의 상체 회전 키프레임을 **하나의 별도 GLB 애니메이션으로 구워서 저장**합니다. 손목을 매 프레임 임의로 움직이지 않습니다.
- 왼발 발끝이 내려갔던 원본 보행 주기의 약 0.53~0.82초 구간에 국소적인 발목 들기 보정 곡선을 기록했습니다.
- `scripts/preview/mocap_5s_reworked.gd`: 발바닥/발끝 근처의 바닥 기준을 전체 1.2초 보행 주기로 보정합니다.
- `tests/mocap_reworked_local.gd`: 실제 GLB 파일의 300프레임 왼발 높이와 팔 애니메이션 움직임 검사.
- `tools/tests/test_author_mocap_composite.py`: 애니메이션 보정 수학의 단위 검사 (CI에서 외부 GLB 없이 실행).

## 미완료 / 주의

**발끝 관절의 높이를 확인한 것과 신발 메시가 지면을 절대로 관통하지 않는다는 것은 다릅니다.**

또한 상체 팔 움직임이 추가되었지만 **군인용 원본 리그와 상체 자세가 최종 게임 수준으로 자연스럽다고 승인하지 않았습니다.** 실제 무사시 모델 및 이도류 자세와 완전히 일치하는 모션을 만들려면, Blender에서 손가락·손목·어깨·골반·발바닥을 통합 보정하고 육안으로 재검증해야 합니다. 기존 `main`을 그대로 유지하고 이 제작 실험은 Draft PR에서 관리합니다.
