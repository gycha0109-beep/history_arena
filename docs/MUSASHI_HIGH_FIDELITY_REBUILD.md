# 무사시 고품질 외형 재제작 — 기준 및 승인 조건

기준: 사용자가 2026-11-14 제공한 원본 무사시 설정 시트. 기존 V3 렌더는 불합격.
작업 원칙: 기존 절차적 겉옷, 얼굴, 상투를 미세 조정하지 않는다. 기존 Blender 파일/리그/무기 데이터는 백업으로 보존한다.

## 가장 중요한 결함
- 목표: 실사풍 얼굴, 낡은 겹옷 주름과 올 풀림, 풍성한 검은 묶은 머리, 자연스러운 체형, 붉은 허리띠.
- 현재: 범용 인체 위에 단순한 메시를 수식으로 얹어놓아 형태와 재질 모두 부족.
- 기존 방식은 품질 상한선이 목표보다 현저히 낮다. 렌더링 설정만으로 해결할 수 없다.

## 작업 순서
1. 원본 설정 시트를 보존하고, 동일한 중립 포즈로 정렬된 정면/측면/후면 제작.
2. 텍스처가 있는 고품질 인물/의상/헤어 기반 에셋을 확보해 실제 편집 가능한 Blender 파일에서 확인.
3. 얼굴·머리 실루엣·겹옷 형태를 기준 시트와 직접 비교하고 미달이면 교체.
4. 피부·천·띠·붕대·신발 재질과 찢어진 솔기 디테일을 추가.
5. 중립 자세 기준 4방향 동일 캐릭터 검증(얼굴, 손, 발, 무기 고정).
6. 모델 승인 후에만 리토폴로지, 리깅, 걷기/베기/피격 작업 재개.

## 승인 조건
- 세 카메라 방향에서 의상과 얼굴이 동일한 인물로 인식된다.
- 체형과 옷 실루엣이 목표와 명백히 일치한다.
- 무기는 손에 고정되어 길이가 변하지 않는다.
- Blender 편집 가능한 최종 모델, GLB, 4뷰 렌더와 HTML 비교가 모두 존재한다.
- 이미지 한 장의 유사도가 아니라 실제 모델을 회전해서 확인한다.

## 주의
- 원본 3/4 컷은 전투 포즈라 중립 다중 시점 입력에 혼합하지 않는다.
- 참조 시트의 각 뷰는 팔 위치 등이 달라 그대로 다중 시점 AI에 넣으면 형태 왜곡 위험이 있다.
- 로컬 PC에서 원본 목표 시트 파일을 확보하기 전에는 자동 이미지→3D 실행을 확정하지 않는다.
- 다운로드나 툴 도입은 실제 성공 여부가 확인되기 전까지 '완료'로 보고하지 않는다.
