# 자율 대전 계산 프로토타입 v0.1

## 구현된 기능

- **60회/초의 고정 전투 업데이트:** 가상 공간에서 두 인물의 이동과 공격 처리
- **캐릭터별 차이:** 무사시는 긴 검 사거리와 높은 단발 피해량, 이소룡은 빠른 이동과 빠른 근접 타격
- **공격의 준비·유효·회복 시간:** 각 기술별로 다른 시간과 피해량 적용
- **거리 기반 공격 판정:** 실제 3D 검/신체 히트박스는 아직 없음
- **자율 AI:** 거리와 공격 가능 여부에 따라 접근·후퇴·기술 선택
- **템포 보조:** 6초 이상 적중이 없으면 AI의 접근 속도와 공격 선택 가능성 증가. 승자·피해량·명중 여부는 직접 조작하지 않음
- **경기 결과:** KO 또는 75초 제한 시 체력 비교
- **경기 기록:** 시작 난수값, 사건 목록, 60Hz 상태 기록. 동일 엔진/규칙에서 같은 시작값의 시뮬레이션 결과가 일치하는지 테스트
- **재대결:** 개발용 실행 화면에서 R키를 누르면 새로운 시드로 경기 시작

## 현재 한계 (완료라고 오해하지 말 것)

- **3D 캐릭터·검·애니메이션·이펙트 없음.** 실행 화면은 테스트 HUD와 무대 바닥만 있음
- **실제 히트박스/허트박스 없음.** 간단한 1차원 거리 비교만 수행
- **방어·회피·콤보·무기와 신체 충돌·다운 없음.** 차기 전투 시스템 단계에서 추가할 항목
- **제작 완성형 밸런스 아님.** 능력치는 테스트용 수치이며 역사적 전투력 판정이 아님
- **정확한 리플레이 플레이어 없음.** 상태를 기록하지만, 기록된 프레임으로 영상을 재생하는 기능은 아직 미구현
- **촬영/세로 영상/MP4 출력 없음.** 렌더링과 영상 후처리 기능 미구현
- **그래픽 품질 검증 미진행.** 실제 캐릭터 모델과 모션이 확보돼야 확인 가능

## 코드 위치

- `scripts/core/fighter_state.gd`: 캐릭터 체력·위치·상태
- `scripts/core/match_session.gd`: 공통 경기 틱·시작·종료·사건 기록
- `scripts/core/combat_simulator.gd`: 현재 자동 대전 규칙·공격 판정·간단한 AI
- `scripts/main.gd`: 전투 계산 상태를 보여주는 임시 실행 화면
- `tests/combat_simulation.gd`: 여러 시작값에 대한 종료·체력·거리·경기 기록 일치 여부 검사

## 테스트

```powershell
godot --headless --editor --path . --quit
godot --headless --path . --script res://tests/smoke.gd
godot --headless --path . --script res://tests/combat_simulation.gd
```

**중요:** Godot에서 실행 성공 및 자동 테스트 통과 여부는 GitHub Actions 결과 또는 실제 PC 실행으로 확인한 뒤 최종 기록한다. 코드를 추가한 사실만으로 검증 완료라고 쓰지 않는다.
