# 무사시 이도류 — 양손 검 연결 및 5초 영상 검증

> 2026-11-12. 실제 무사시 원본 모델을 확보하기 전까지는 **제작 기술 확인용 임시 인체 모델**을 사용합니다. 이 문서는 최종 외형이나 완성된 검술 애니메이션을 주장하지 않습니다.

## 확정 방향

- **오른손: 장검(카타나)**
- **왼손: 단검(와키자시)**
- 두 검은 각각 서로 다른 손뼈에 연결하며, 검 하나를 허리에 보관하는 대체안은 사용하지 않습니다.
- 무기 메시에는 스킨·모프·스케일 애니메이션을 사용하지 않습니다. 뼈의 위치·방향만 따라가며 고정 길이를 유지합니다.
- 앞으로 실제 캐릭터의 공격 애니메이션도 두 손을 함께 사용하도록 제작합니다.

## 발견된 문제와 실제 수정

| 문제 | 원인 | 조치 |
|---|---|---|
| 머리가 디용거리며 흔들림 | 임시 보행 모션의 목·몸통 흔들림과 반복 재생 | 목 회전 고정, 몸통 상하 변위 감쇠, 자동 애니메이션 재적용 중단 |
| 칼을 잡고 있는 느낌 부족 | 손뼈 원점과 칼 손잡이 중앙 불일치 + 손가락 관절 없음 | 손잡이 중심에 무기 원점 배치, 임시 손바닥·구부린 손가락 형상 추가 |
| 한 자루만 보임 | 코드가 단일 무기만 연결 | 장검과 단검의 별도 GLB/별도 손뼈/별도 소켓으로 분리 |
| 다리 제자리걸음 | 기본 보행 애니메이션이 5초 내내 반복 | 오른발/왼발의 실제 접지 프레임을 추출해 정지 자세 구성 |
| 양손 자세가 영상에 반영되지 않음 | AnimationPlayer 자동 업데이트가 지정한 자세를 덮어씀 | 수동 타임라인 재생으로 변경 |
| 검이 아래나 화면 안쪽을 향함 | GLB 좌표축을 잘못 가정 | 검날 실제 모델 축(+Y)을 확인하고 소켓 회전을 보정 |
| 화면이 작음 | 기존 3D 카메라가 멀리 있음 | 세로 영상용 카메라 구도 확대 |

## 실제 결과

- 렌더링: **Godot 4.7.2**, 학원 PC **GTX 1060 3GB**
- 시험 모델: Khronos glTF Sample Assets CesiumMan (최종 캐릭터 아님)
- QA 장검: 약 0.83m 블레이드, 0.27m 손잡이
- QA 단검: 약 0.49m 블레이드, 0.205m 손잡이
- 영상: **720×1280, 60fps, 300프레임, 5.0초**
- 검 크기 변형 최대 오차: 장검 약 0.00000013, 단검 약 0.00000018
- 검 손잡이 중심–손목 소켓 연결 오차: 두 검 모두 0.0000000
- 머리 회전 최대 편차: 0도(수동 고정)
- 머리 수직 위치 변화 폭: 약 0.0056m(5.6mm)
- **로컬 이도류 실물 검사:** `tests/dual_wield_qa_local.gd` 통과
- **배포용 검사:** 무사시의 장검·단검 및 각 손뼈 경로가 없으면 실패하도록 설정
- 사용한 임시 모델에는 **손가락 관절이 없어서 실제 손가락 리깅 검증은 못 했습니다.** 임시 손가락 모양은 검 메시 일부이며 최종 모델에서는 제거해야 합니다.

## 파일과 실행법

```powershell
# 현재 학원 PC에 임시 인체/두 검 GLB가 준비된 상태
.\run-dev.cmd -Mode dualqa

# 구조·AI·이도류 설정 자동 검사
.\run-dev.cmd -Mode test

# 로컬 GLB가 있을 때 손·발·머리·무기 변형 검사
godot --headless --path . --script res://tests/dual_wield_qa_local.gd
```

영상: `D:\cha\History_arena\captures\qa\dual_wield_final.mp4`

HTML 재생기: `D:\cha\History_arena\captures\qa\dual_wield_preview.html`

QA 인체 파일: `samples/external/CesiumMan.glb`, 장검 `samples/external/qa_katana_dual.glb`, 단검 `samples/external/qa_wakizashi_dual.glb`.

이 세 GLB는 Git에서 추적하지 않으며, 검은 `blender --background --python tools/build_dual_qa_swords.py`로 다시 만들 수 있습니다. 테스트 인체 파일 출처/라이선스는 `docs/LOCAL_3D_QA.md` 참고.

## 다음 필수 작업

1. 실제 무사시 반실사 모델 및 손가락 관절 포함 리깅 확보.
2. 손가락으로 장검·단검 손잡이를 **실제로 쥐는 모션** 제작. 임시 손바닥 형상을 제거.
3. 이도류 장검 베기/단검 견제/양손 합동 기술을 Blender에서 제작하고 Godot에 연결.
4. 검날 방향·무기 피격 판정과 상대의 피격 애니메이션 타이밍을 실제 장면에서 검증.
5. 5초 장면에 실제 이소룡 모델을 추가하고 고품질 2인 전투 비주얼을 검증.

임시 이도류 QA 영상이 성공해도 이 단계가 끝난 것은 **아닙니다**.
