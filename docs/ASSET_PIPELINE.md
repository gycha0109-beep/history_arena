# 2.5D 캐릭터·애니메이션 제작 지침 v0.1

## 제작 흐름

1. **캐릭터 확보** — 실존 인물의 디자인 방향을 정하고 사용 가능한 리깅된 모델 또는 합법적으로 제작한 원본 확보
2. **Blender 정리** — 외형, 스케일, 본, 발 기준점, 무기 메시, 좌우 방향 확인
3. **모션 재활용** — Mixamo 등의 상업적 사용 가능 모션을 불러와 리타기팅하고 캐릭터 고유 동작을 수정
4. **검·무기 결합** — 검을 늘어나게 변형하지 않고, 오른손/왼손의 지정된 부착 지점에 별도 모델로 연결
5. **애니메이션 표준화** — `idle`, `walk_forward`, `walk_backward`, `attack_light`, `attack_heavy`, `block`, `dodge`, `hit_react`, `ko`
6. **내보내기** — 가능하면 캐릭터·애니메이션이 포함된 GLB로 Godot에 가져오고 import 상태 확인
7. **Godot 시연** — 바닥 접지, 공격 타이밍, 무기 길이, 몸통 회전, 후속 동작 자연스러움 확인

## 공통 규칙

- 게임 좌표: X는 좌우, Y는 위아래, Z는 무대 깊이
- 캐릭터의 기본 전투 평면은 Z값 고정. 모델 회전은 시각적 표현, 판정 데이터는 별도
- 캐릭터의 실제 이동(루트 모션)과 게임이 계산한 이동량이 중복 적용되지 않도록 규칙 수립
- 동일한 공격의 시작·유효·회복 시점은 시각 동작과 히트박스 데이터가 일치해야 함
- 무기는 가능한 별도 메시로 손 본/소켓에 연결. 비정상적인 메시 스케일 애니메이션 금지
- 모델용 본 구조가 달라도 공통 게임 행동 이름을 유지
- AI 생성 영상에서 추출한 스프라이트 시트는 기본 파이프라인에 넣지 않음

## 첫 품질 검증 장면

**무사시 vs 이소룡, 5초짜리 고정 장면**: 대치 → 접근 → 검격 → 피격/회피 → 회복.

통과 기준:
- 검 길이·형태·손 연결 위치가 전 프레임에서 유지
- 신체·얼굴 비율 불규칙 변형 없음
- 발 미끄러짐과 동작 뚝 끊김 없음
- 기본 공격과 피격 반응의 타이밍이 납득 가능
- 동일한 모델에 두 번째 모션을 재사용할 수 있음
- PC 개발 환경의 실제 프레임/렌더링 성능은 별도 측정

## 에셋 권리 관리

모델·애니메이션·음원마다 원본 URL, 제작자, 라이선스 원문 링크, 상업적 이용·변형·재배포 허용 범위, 취득 날짜를 기록한다. 실존 인물의 초상 및 플랫폼 정책은 별도 검토한다.
