# 검증 기준 v0.1

## 자동으로 가능한 검사

`godot --headless --editor --path . --quit`: 프로젝트 파일과 스크립트 import 확인.
`godot --headless --path . --script res://tests/smoke.gd`: 틱·경기 시작/종료·이벤트 기록 형식 확인.

GitHub Actions에서 **Godot 4.7.2**를 다운로드하여 위 두 명령을 수행하도록 구성한다.

## PC에서 추가 확인할 항목

1. Godot 프로젝트 열기 및 기본 장면 실행
2. GTX 1070에서 캐릭터 2개 + 배경 렌더 성능 측정
3. 무사시 검의 길이·부착점·메시 스케일 일정성
4. 이동 발 접지, 공격 시작/적중/회복, 피격 동작 품질
5. 판정과 시각 효과 분리 확인
6. 서로 다른 재대결 결과, 동일 기록의 정확한 재생
7. 세로형 MP4 출력, 검격·피격 싱크와 화질 확인

## 판정 규칙

- 테스트 자동 통과 ≠ 그래픽 품질 통과
- Godot 프로젝트 실행 ≠ 전투 시스템 완성
- 경기 이벤트 기록 ≠ 결정론적 리플레이 완성
- 품질 검증에는 실제 5초 장면과 사용자 시각 평가가 필수

## 5초 장면 추가 검사

- `godot --headless --path . --script res://tests/five_second_preview.gd`: 300프레임 타이밍·접근·공격·피격·상태 종료 및 실제 GLB 누락 경고
- **자동 검사에는 실제 모델이 없으므로** 메시 변형/발 접지/고품질 영상 완성도를 검사하지 못합니다.
- 육안 품질 검사: `run-dev.cmd -Mode preview`, 모델 확보 후 `run-dev.cmd -Mode record`.
