# 제작 단계와 성공 기준

## 0단계 — 저장소 기반 (현재 작업)
- Godot 4.7.2 기본 프로젝트, 기본 메인 씬, 틱/기록 구조
- 문서/에셋 규격, Git LFS 설정, GitHub 자동 기본 검사
- 성공 기준: GitHub 자동 검사가 성공하고 PC에서 Godot 프로젝트를 열 수 있음
- **현재 실제 PC 실행 검증 전**

## 1단계 — 그래픽 품질 검증 (가장 중요)
- 무사시 모델/리그/검 메시 확보, 검격 애니메이션 1개
- 이소룡 모델과 피격/회피 애니메이션
- Godot에서 두 캐릭터 5초 장면 연출 및 영상 출력
- 검 길이·신체 비율·접지·충돌 타이밍 품질 확인
- **통과하지 못하면 AI나 대규모 캐릭터 추가보다 제작 방식을 개선**

## 2단계 — 실제 1:1 전투 (현재 간이 전투 계산·AI 초안만 선행 구현)
- 이동·거리·기술 시작/유효/회복 상태
- 히트박스·허트박스·가드·피격·KO 구현
- 서로 다른 특성·사거리의 무사시/이소룡 적용
- 무인 조작 상태에서 한 경기 종료

## 3단계 — 자율 대전과 재대결
- 규칙 기반 + 유틸리티 점수 AI
- 소극적 대치·반복만 완화하는 템포 보조
- 실제 승패, 경기 로그, 여러 경기 선택
- 재생 영상과 원본 경기 판정 일치 확인

## 4단계 — 숏폼 생산 시스템
- 일반 전투 카메라 + 결정적 순간 시네마틱
- 전투 시뮬레이션과 고품질 오프라인 영상 렌더링 분리
- 9:16, 1080×1920, 30~60초 MP4 목표
- 여러 경기 중 하나 선택 → 릴스용 영상 출력

## 우선순위 제외
온라인 멀티플레이, 사람 조작 중심의 상용 게임 기능, 복잡한 메뉴, 웹 서버, 데이터베이스, 실시간 LLM 연결.

## 운영 원칙
완성된 기능과 검증되지 않은 설계를 반드시 구분한다. 세부 수치는 실제 품질·성능 테스트를 통과해야 최종 확정한다.

## 기초 전투 계산 작업 기록

그래픽 에셋 확보 전, 캐릭터 상태·60Hz 간이 거리 판정·자율 이동/공격 선택·KO·시간 제한·경기 상태 기록을 별도로 구현함. 실제 3D 캐릭터·검·피격 애니메이션·정교한 히트박스 연결 전이므로 **2·3단계 완료로 간주하지 않음**. 상세: [자동 대전 프로토타입](COMBAT_PROTOTYPE.md).

## 3D 모델 연결 기반 (2026-11-12)

실제 모델을 넣을 수 있도록 GLB·애니메이션·무기 소켓 연결 코드 및 검 크기 보호 테스트를 추가. 외부 Meshy 결과물은 미확보 상태이며, **5초 고품질 모션 품질 검증 단계 완료를 의미하지 않음**. [연결 실행서](MESHY_TO_GODOT.md).
